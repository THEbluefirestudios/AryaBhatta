Aryabhata Website 🧮

This is a website I made about Aryabhata, one of the famous mathematicians and astronomers from ancient India.

I made this project while learning HTML and CSS. I wanted to make something more than just a basic HTML page, so I added a proper design, background image, navigation bar, sections and some animations.

What is in this website?
About Aryabhata and Aryabhatiya
Structure and style
Contents of the book
Significance of his work
Influence of Aryabhatiya
Some basic animations and hover effects
Responsive design for smaller screens
